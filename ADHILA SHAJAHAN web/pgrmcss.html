CSS

CSS stands for Cascading Style Sheets. It is a foundational style sheet language used to describe the visual presentation, layout, and formatting of documents written in markup languages like HTML or XML. Along with HTML and JavaScript, CSS is a cornerstone technology of the World Wide Web.
